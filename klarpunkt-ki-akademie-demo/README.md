# Klarpunkt KI-Akademie — Demowebseite

Demo-Schulungswebseite für ein fiktives KI-Weiterbildungsangebot. Zeigt Kursangebot, Terminbuchung und Buchungsbestätigung als vollständige Vorlage für ein Kursbuchungs-Projekt.

## Inhalt

- **Start** — Kurzvorstellung, nächste freie Termine, Kundenstimmen
- **Kursangebot** — filterbare Kurskarten mit aufklappbaren Kursinhalten
- **Terminbuchung** — Formular mit Kurs-/Terminauswahl, Live-Preisberechnung, Validierung
- **Bestätigung** — generierte Buchungsnummer, Zusammenfassung, nächste Schritte
- **Kontakt** — Kontaktdaten und FAQ

## Technik

Eine einzelne, selbständige Datei `index.html` (HTML, CSS, Vanilla JavaScript). Kein Build-Schritt, kein Backend. Schriften via Google Fonts (Fraunces, Work Sans, IBM Plex Mono). Unterstützt Hell/Dunkel-Theme nach Systemeinstellung.

## Lokal ansehen

`index.html` direkt im Browser öffnen, oder im Projektordner einen einfachen Server starten, z. B. `python3 -m http.server`.

## Hinweis

Reine Demo — es werden keine echten Buchungen gespeichert oder E-Mails versendet. Dient als Referenz-Vorlage für künftige Kundenprojekte im Bereich Kursbuchung.

Dokumentation (Bedienungsanleitung, IT-Datenblatt) liegt im zugehörigen Notion-Projekt „Webseite Klarpunkt KI-Akademie (Demo)".
